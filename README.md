## Overview
Myflix app
Description

This app is built using React and React Bootstrap, providing users with an interactive interface to explore a collection of movies. After logging in, users can view a comprehensive list of films, along with detailed information such as the director and genre for each movie. Users also have the option to add movies to their favorites for easy access later.
Features

    User authentication: Users can sign up and log in to access the app.
    Movie list: A dynamic list displaying available movies with essential details.
    Movie details: View additional information for each movie, including the director and genre.
    Favorites: Users can add movies to their favorites list for quick reference.

Technologies Used

    React
    React Bootstrap
    CSS
    API for fetching movie data 

### Essential Views & Features

- **Main View:**
  - Displays all movies, each with an image, title, and description.
  - A search feature to filter the list of movies.
  - Ability to select a movie for more detailed information.
  - Ability to log out and navigate to the Profile view.

- **Single Movie View:**
  - Displays detailed information about a selected movie (description, genre, director, and image).
  - Users can add a movie to their list of favorites.

- **Login View:**
  - Allows existing users to log in using their username and password.

- **Signup View:**
  - Allows new users to register with their username, password, email, and date of birth.

- **Profile View:**
  - Displays user registration details.
  - Allows users to update their information (username, password, email, date of birth).
  - Displays favorite movies and allows users to remove movies from the list.
  - Allows existing users to deregister their account.
