Myflix app
Description

This app is built using React and React Bootstrap, providing users with an interactive interface to explore a collection of movies. After logging in, users can view a comprehensive list of films, along with detailed information such as the director and genre for each movie. Users also have the option to add movies to their favorites for easy access later.
Features

    User authentication: Users can sign up and log in to access the app.
    Movie list: A dynamic list displaying available movies with essential details.
    Movie details: View additional information for each movie, including the director and genre.
    Favorites: Users can add movies to their favorites list for quick reference.

Technologies Used

    React
    React Bootstrap
    CSS
    API for fetching movie data
